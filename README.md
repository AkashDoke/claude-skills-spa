# Claude Skills — Enterprise AI Presentation SPA

A premium, presentation-ready Single Page Application showcasing Claude AI Skills.

## Quick Start

```bash
npm install
npm run dev       # → http://localhost:5173
npm run build     # production build
npm run preview   # preview production build
```

## Keyboard Navigation
- Arrow Down / Page Down → Next section  
- Arrow Up / Page Up → Previous section

## Sections
1. Hero — Animated headline, particle system, CTAs
2. What Are Skills? — Concept explanation, feature pillars
3. Skills Showcase — 6 interactive cards with expand modals
4. Workflow — Animated step-by-step process flow
5. Business Use Cases — Industry vertical tabs
6. AI Dashboard — Live metrics, charts, activity feed

## Tech Stack
- React 18 + Vite 6
- Tailwind CSS 3
- Framer Motion 12
- Lucide React Icons

## Customization
- Edit `src/data/index.js` to update skills, metrics, and use cases
- Add sections in `src/sections/` and register in `src/App.jsx`
- Modify colors in `tailwind.config.js` and `src/index.css`

Built for executive demos, client presentations, and enterprise showcases.
